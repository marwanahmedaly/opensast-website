Every product command

CommandPurpose / useful options
setupGuided provisioning. --reconfigure, --offline, --non-interactive, --yes, --no-start; engine/model/path/port options.
doctorCheck tool, pack, model API and dashboard readiness.
start / stop / restartManage recorded local services and remembered workers.
bootstrap --username NAMEManual initial administrator; --workspace NAME, --data PATH. Private password prompt.
serveAPI/dashboard; --host, --port, --data, --public-url, repeated --trusted-origin.
login --username NAME / logout / passwordCLI session and password management; --server URL selects backend.
initRegister current checkout; --workspace, --name, --project, --no-browser, --no-worker.
projects / dashboardList accessible projects or open the dashboard.
workspace list / workspace create NAMEList or create workspaces.
members WORKSPACE_IDList/manage membership; --username, --role admin/member/viewer/remove, --new-user.
audit WORKSPACE_IDRead workspace audit events.
scanQueue analysis; --full bypasses reuse, --wait waits for completion.
statusShow project job status; --job JOB_ID selects a job.
cancel JOB_IDCancel a queued or running job.
findings JOB_IDRead saved findings.
export JOB_ID --output PATHSave complete JSON result.
review JOB_ID FINDING_ID STATESTATE: open/confirmed/dismissed; --note records reviewer explanation.
worker-tokenRotate credential, or --import to paste privately.
workerServe this checkout’s queue; --once, --suspect-only, engine options.
ciIndependent Git-aware scan; required --project-key, --state, --output; --base, --full, --fail-on new/none and engine options.

Run opensast --help or opensast COMMAND --help for the installed version’s exact syntax. Project commands run from a registered checkout. User and workspace operations require login; standalone CI does not.

Worker and CI engine options

--codeql /path/to/codeql
--query-search-path /path/to/packs
--endpoint http://127.0.0.1:8000/v1
--model SERVED_MODEL_NAME
--model-revision IMMUTABLE_WEIGHT_REVISION
--allow-model-host inference.company.internal
--context-window 16384
--max-tokens 400

Saved setup defaults are used when options are omitted. --allow-model-host can be repeated. A model revision is required for CI and for verified-result cache reuse.

Useful terms

TermMeaning
CWEA weakness category, such as SQL injection (CWE-89).
Source / sinkInput origin / security-sensitive operation. A relationship can be suspected without being an exploitable path.
Candidate / suspectAn operation surfaced by static discovery before a final verification decision.
Evidence packetFocused, file/line-referenced code and relationships sent to the verifier.
Verdict / review stateModel judgment / separate human conclusion.
Worker / jobProcess on the source machine / a requested scan tracked by the backend.
Baseline / cacheEarlier successful scan identity / reusable exact decisions and results.
Model revisionImmutable identifier for the actual served weight bytes, not merely a friendly model name.
