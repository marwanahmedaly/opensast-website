01 / HOW TO READ

Understand the comparison first.

Precision: how many flagged labeled cases were truly vulnerable. Recall: how many known vulnerable cases were detected. F1 balances precision and recall.

Repository evaluations score selected operations, not all code in the repositories. OWASP scores all 293 official tests in the four-CWE scope. These percentages do not describe the complete repository alert stream. Each evaluation retains its own configuration and prior exposure.

02 / EVALUATION METHOD

What counts as a correct finding?

Each study retains its own configuration, revisions and scoring unit. Scanning every candidate does not establish truth for every operation.

Official benchmark

Test-case labels

All 293 official cases for the four CWEs: 114 vulnerable and 179 negative. OWASP results are test-level scores.

Repository panels

Operation matching

Advisories, fixing commits and reviewed contracts identify operations and conditions. A finding in the same file is not automatically a match.

Human follow-up

Reported human confirmation

An AI coding agent initially reviewed repository findings. The project author reported subsequent human confirmation; reviewer identity, finding coverage and agreement were not recorded.

Unknown truth is excluded from resolved metrics and reported separately. An unresolved prediction on a known vulnerable case can still be a missed detection.

Thesis §§4.3, 4.6–4.7. Shared model settings do not mean identical detector configurations: Tables 4.3–4.4 distinguish the recorded source snapshots.

05 / INTERPRETATION

Coverage gains with explicit limits.

The comparison supports claims about these labeled sets, not universal production superiority.

  • 31-project repository evaluation: much higher labeled-case recall and F1, slightly lower labeled-case precision, and lower precision in the broader emitted alert stream.
  • 7-project repository evaluation: higher labeled-case precision, recall and F1 than stock, on a small previously investigated panel.
  • OWASP Python benchmark evaluation: higher aggregate precision, recall and F1 than stock. All 31 vulnerable XSS tests were missed before verification.
  • All three sets were exposed during development or investigation. Earlier seven-project records remain archived; the presented panel is not an independent unseen-project test.
