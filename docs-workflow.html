Step 1 — Prepare the runner

Use an isolated company self-hosted Linux runner with the trusted OpenSAST executable, CodeQL packs and local/internal model already provisioned. Keep scanner installation and private state outside the target checkout. The CI setup guide explains access and version boundaries.

Step 2 — Create the workflow file

In the Python repository you will scan, create .github/workflows/opensast.yml. Copy this complete example, then change the settings in step 3.

# Copy to .github/workflows/opensast.yml in the target Python repository.
# Provision the trusted CLI, CodeQL packs and local model on an isolated company
# runner first. Do not install the scanned repository or run its setup scripts.
name: OpenSAST
on:
  pull_request:
  push:
    branches: [main]
  workflow_dispatch:
permissions:
  contents: read
concurrency:
  group: opensast-${{ github.repository }}-${{ github.ref }}
  cancel-in-progress: false
jobs:
  scan:
    # This example deliberately excludes fork PRs from the internal runner.
    if: github.event_name != 'pull_request' || github.event.pull_request.head.repo.full_name == github.repository
    runs-on: [self-hosted, linux, opensast]
    steps:
      - uses: actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683 # v4.2.2
        with:
          fetch-depth: 0
          persist-credentials: false
          ref: ${{ github.event.pull_request.head.sha || github.sha }}
      - name: Scan with trusted OpenSAST
        # Pin the action to a reviewed integration commit.
        uses: marwanahmedaly/opensast/.github/actions/opensast@2175c1ac26fe4100d822891c4b7488df598e54a8
        with:
          executable: /opt/opensast/bin/opensast
          project-key: ${{ github.repository }}
          base: ${{ github.event.pull_request.base.sha || '' }}
          state: /var/lib/opensast/ci
          output: ${{ runner.temp }}/opensast-${{ github.run_id }}-${{ github.run_attempt }}/report.json
          codeql: /opt/codeql/codeql
          query-search-path: /opt/codeql/packages
          endpoint: http://127.0.0.1:8000/v1
          model: qwen3-coder
          model-revision: REPLACE_WITH_WEIGHT_SHA256
          fail-on: new
      # No actions/cache or upload-artifact: full source/evidence remain internal.

Step 3 — Replace the example settings

SettingWhat to enter
Runner labelsLabels matching your approved company runner: self-hosted, linux, opensast in this example.
Executable and CodeQL pathsActual trusted installation paths on the runner; do not point to code supplied by the scanned pull request.
State / outputPrivate directories outside the checkout. Keep state persistent for reuse.
Endpoint / modelYour local or internal inference URL and the exact served model name.
Model revisionReplace REPLACE_WITH_WEIGHT_SHA256 with the immutable digest of the actual served weights.
Action revisionThe example pins the public merged Action at 2175c1ac26fe4100d822891c4b7488df598e54a8. Review the scanner/action pairing for your runner.

The new 0.2.0 installer is not validated by the historical action checks. Do not substitute an unreviewed scanner revision merely to make the workflow run.

Step 4 — Commit and inspect a run

Commit the workflow and use a permitted same-repository pull request, a push to main, or Run workflow in GitHub Actions. An approved runner must be online. The first PR comparison scans the base and head snapshots.

Expected result: the OpenSAST job completes with a check status; the detailed JSON report is stored at the configured runner-local path. The template does not upload that report to GitHub or the dashboard.

If it fails: check runner labels, action access, paths, model readiness and the pinned weight revision. Exit 1 means an execution failure or alert gate failure; exit 2 means incomplete verification. Read report and gate behavior.

Advanced — Composite action source

The following is the composite action source from the public OpenSAST repository. It matches the merged integration commit pinned by the workflow above.

name: OpenSAST local-first scan
description: Full Python static analysis with cached verification and Git baseline comparison on a company runner
inputs:
  executable:
    description: Absolute path to the preinstalled trusted OpenSAST executable
    default: /opt/opensast/bin/opensast
  project-key:
    description: Stable repository identifier
    required: true
  base:
    description: Optional PR target commit; its merge-base is the comparison baseline
    default: ''
  state:
    description: Persistent private cache outside the checked-out repository
    required: true
  output:
    description: Private JSON report outside the checkout
    required: true
  codeql:
    description: Absolute path to preinstalled CodeQL
    required: true
  query-search-path:
    description: Preinstalled CodeQL pack directory
    required: true
  endpoint:
    description: Internal OpenAI-compatible inference endpoint
    required: true
  model:
    description: Model name
    required: true
  model-revision:
    description: Immutable model revision or weights digest
    required: true
  allow-model-host:
    description: Optional explicitly allowed internal inference hostname
    default: ''
  fail-on:
    description: 'new (fail on new alerts) or none (report only); unresolved results always fail'
    default: new
outputs:
  report:
    description: Path to the full report on the company runner
    value: ${{ steps.scan.outputs.report }}
  exit-code:
    description: '0 completed, 1 new alerts or execution failure, 2 incomplete verification'
    value: ${{ steps.scan.outputs.exit-code }}
runs:
  using: composite
  steps:
    - id: scan
      shell: bash
      env:
        OPENSAST_EXECUTABLE: ${{ inputs.executable }}
        OPENSAST_PROJECT: ${{ inputs.project-key }}
        OPENSAST_BASE: ${{ inputs.base }}
        OPENSAST_STATE: ${{ inputs.state }}
        OPENSAST_OUTPUT: ${{ inputs.output }}
        OPENSAST_CODEQL: ${{ inputs.codeql }}
        OPENSAST_PACKS: ${{ inputs.query-search-path }}
        OPENSAST_ENDPOINT: ${{ inputs.endpoint }}
        OPENSAST_MODEL: ${{ inputs.model }}
        OPENSAST_REVISION: ${{ inputs.model-revision }}
        OPENSAST_MODEL_HOST: ${{ inputs.allow-model-host }}
        OPENSAST_FAIL_ON: ${{ inputs.fail-on }}
      run: |
        [[ "$OPENSAST_EXECUTABLE" = /* ]] || { echo "OpenSAST executable must be an absolute trusted path" >&2; exit 1; }
        arguments=(ci --project-key "$OPENSAST_PROJECT" --state "$OPENSAST_STATE"
          --output "$OPENSAST_OUTPUT" --codeql "$OPENSAST_CODEQL"
          --query-search-path "$OPENSAST_PACKS" --endpoint "$OPENSAST_ENDPOINT"
          --model "$OPENSAST_MODEL" --model-revision "$OPENSAST_REVISION"
          --fail-on "$OPENSAST_FAIL_ON")
        if [[ -n "$OPENSAST_BASE" ]]; then arguments+=(--base "$OPENSAST_BASE"); fi
        if [[ -n "$OPENSAST_MODEL_HOST" ]]; then arguments+=(--allow-model-host "$OPENSAST_MODEL_HOST"); fi
        # Source/evidence stay local. Print only status in Actions logs.
        umask 077
        mkdir -p "$(dirname "$OPENSAST_OUTPUT")"
        set +e
        "$OPENSAST_EXECUTABLE" "${arguments[@]}" > "$OPENSAST_OUTPUT.console.log" 2>&1
        status=$?
        set -e
        printf 'report=%s\nexit-code=%s\n' "$OPENSAST_OUTPUT" "$status" >> "$GITHUB_OUTPUT"
        printf 'OpenSAST completed with exit code %s. Detailed report remains on the company runner.\n' "$status"
        exit "$status"
